# Max–Min Semantic Chunking

This repository contains the code and experimental results for evaluating Max–Min semantic chunking for dense retrieval.

## Experiments

- **Experiment 001:** Qwen3-Embedding-0.6B on AI4Bharat MSMARCO-XI.
- **Experiment 002:** BGE-M3 on AI4Bharat MSMARCO-XI.
- **Experiment 003:** BGE-M3 on MLDR Hindi.

The notebooks include the original experimental workflow, including debugging, intermediate experiments, and evaluation code.
